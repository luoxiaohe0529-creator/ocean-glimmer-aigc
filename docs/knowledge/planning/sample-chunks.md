# 广告策划知识库｜公开样例块

来源 Wiki：<https://pcn7bpsihajy.feishu.cn/wiki/XLdRwFy4RiDNvykEXXtcc39UnIe>

> 以下内容为脱敏样例，用于展示知识块粒度和调用方式，不是完整飞书正文。

## chunk planning-001

| 字段 | 内容 |
| --- | --- |
| role | planning |
| stage | stage-1 |
| content_type | 真人口播带货 / 好物推荐 / 高端 TVC |
| objective | 将商品资料转为可比较的广告创意方向 |

产品事实必须优先于创意表达。生成 Brief 时先记录商品名称、品类、核心卖点、适用场景、目标人群和不可夸大的边界，再把卖点翻译成用户能感知的具体利益。

## chunk planning-002

| 字段 | 内容 |
| --- | --- |
| role | planning |
| stage | stage-1 |
| content_type | 信息流广告 |
| objective | 生成 Hook 池 |

Hook 需要同时包含注意力入口和产品承接点。避免只有情绪口号而没有商品进入方式；每条 Hook 都应能解释“为什么用户此刻要继续看”。

## chunk planning-003

| 字段 | 内容 |
| --- | --- |
| role | planning |
| stage | stage-1 |
| content_type | 高端 TVC |
| objective | 输出 Mood Board 和创意方案 |

Mood Board 不只描述画风，还要给出色彩、光线、场景、材质、节奏和品牌落点。创意方案必须能传给编剧导演继续生成脚本，而不是停留在抽象概念。
