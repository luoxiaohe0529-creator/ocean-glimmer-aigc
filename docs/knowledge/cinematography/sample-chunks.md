> 以下内容为脱敏样例，用于展示知识块粒度和调用方式，不是完整飞书正文。

## chunk cinematography-001

| 字段 | 内容 |
| --- | --- |
| role | cinematography |
| stage | stage-3 |
| content_type | 信息流广告 |
| objective | 把分镜转为视频生成提示词 |

视频提示词要优先锁定产品连续性：外观、颜色、材质、Logo 位置和手持方向不能在镜头间漂移。人物和场景变化必须服务产品展示。

## chunk cinematography-002

| 字段 | 内容 |
| --- | --- |
| role | cinematography |
| stage | stage-3 |
| content_type | 高端 TVC |
| objective | 保持原始 16:9 画面比例 |

TVC 镜头默认按 16:9 构图输出。画面重点是产品主体、光线质感和品牌气质，不裁切、不拉伸，不为了填满界面破坏原始比例。
