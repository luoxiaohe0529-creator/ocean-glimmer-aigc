# 编剧导演知识库｜公开样例块

来源 Wiki：<https://pcn7bpsihajy.feishu.cn/wiki/KikywYv7iiJ0zSkY8HdcLoCEnwf>

> 以下内容为脱敏样例，用于展示知识块粒度和调用方式，不是完整飞书正文。

## chunk directing-001

| 字段 | 内容 |
| --- | --- |
| role | directing |
| stage | stage-2 |
| content_type | 信息流广告 |
| objective | 将已选 Hook 变成完整脚本 |

脚本必须继承用户已确认的 Hook、Mood Board 和创意方案。不要重新发散方向；重点是把选择转译成口播、画面动作和节奏节点。

## chunk directing-002

| 字段 | 内容 |
| --- | --- |
| role | directing |
| stage | stage-2 |
| content_type | 高端 TVC |
| objective | 建立 16:9 叙事结构 |

TVC 脚本以视觉节奏为主，台词只保留必要品牌信息。每个镜头需要交代画面目标、情绪递进和产品露出方式，避免堆叠无关美术描述。

## chunk directing-003

| 字段 | 内容 |
| --- | --- |
| role | directing |
| stage | stage-2 |
| content_type | 好物推荐 |
| objective | 强化使用场景和可信度 |

好物推荐脚本应先给出使用场景，再展示产品细节和对比感受。结尾的行动引导要自然承接前文，而不是突然切换为硬性口号。
